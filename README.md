# 迪諾文字大尋寶 Dino's Word Treasure Hunt

國小生字學習遊戲。這個儲存庫放四個各自獨立的雙語 APP：繁中英、繁中日、簡中英、簡中日。
一個資料夾一個 APP，彼此不共用任何檔案，可以單獨取出使用。

## 四個雙語 APP

| APP | 資料夾 | 語言 | 檔案數 | 大小 |
|---|---|---|---|---|
| **繁中英** | [tw](tw/) | 繁體中文＋英文 | 65,495 | 831 MB |
| **繁中日** | [twja](twja/) | 繁體中文＋日文 | 68,754 | 985 MB |
| **簡中英** | [cn](cn/) | 簡體中文＋英文 | 69,222 | 853 MB |
| **簡中日** | [cnja](cnja/) | 簡體中文＋日文 | 71,619 | 994 MB |

每個資料夾的入口是 `index.html`，詳細說明在各資料夾的 README。

## 注意

- 內容是建置產物，請不要直接在這裡修改。
- 四個 APP 合計約 3.8 GB，超過 GitHub Pages 1 GB 的網站上限，不適合直接用 Pages 發佈整個儲存庫。
- `accounts.js` 裡是測試帳號，而且登入畫面會自動填入。正式上線前請更換並關閉自動填入。
